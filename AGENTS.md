## Development Workflow

The agent must follow four phases:

1. Requirement & Test Design
2. Development & Build
3. Execution & Debug
4. Verification & Report

## Workflow Rules

- Do not modify source code before Test Design approval.
- The approved Test Design is the source of truth.
- Do not silently modify approved requirements.
- Do not claim hardware tests passed without evidence.
- Hardware flashing requires engineer involvement.
- Report blockers and unresolved issues.
- Final verification requires engineer acceptance.
